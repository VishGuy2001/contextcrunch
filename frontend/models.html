Model comparison

Why each model behaves differently

Claude, ChatGPT, and Gemini all have similar token limits on paper — but behave completely differently in practice. Here's what they don't tell you.

Claude

Anthropic
Haiku: 200k Sonnet: 1M Opus: 1M
Memory
Full recall
Keeps the entire conversation context in active attention. Re-reads the complete history on every message turn.
At limit
Honest stop
Explicitly flags when you've hit the context window boundary and refuses to take further input.
Truncation
None
Never silently drops or deletes your previous messages. Keeps accuracy high.
Thinking tokens
Yes (Sonnet/Opus)
Internal reasoning tokens count against context limits invisibly, burning context window capacity faster.
Verdict
Most honest. Stops sooner but guarantees accuracy. The best choice for logic and code tasks where precise memory is vital.
ContextCrunch tip
Use Projects to cache document files. Start fresh threads for new topics. Compress context before memory fill hits 70%.

ChatGPT

OpenAI
Mini: 32k Plus: 272k Pro: 1M
Memory
Silent Truncation
Automatically drops oldest messages when context fills. Never warns or informs you that it is doing so.
At limit
Degradation
The conversation flows smoothly without errors, but responses quietly lose precision on earlier context details.
Truncation
Active - Silent
Removes oldest turns to make room for new prompts. History is lost with no trace in the UI.
Thinking tokens
Yes (o-series)
Reasoning models consume additional hidden tokens to compute logic before outputting text.
Verdict
Smooth and endless, but at the cost of silent amnesia. Good for casual text editing, risky for compound accuracy tasks.
ContextCrunch tip
Manually copy and re-inject core summaries into long ChatGPT threads to keep crucial information loaded in active window.

Gemini

Google
Lite: 1M Pro: 1M Ultra: 2M
Memory
Enormous headroom
Supports up to 2 million tokens (AI Ultra / 3.1 Pro), allowing you to upload entire codebases or research books.
At limit
Rate limits first
On free/unpaid accounts, Studio rate limits (req/min) will trigger long before you can exhaust the token window.
Truncation
Minimal
Maintains long context but effective recall quality degrades at the very extremes (above 1.5M tokens).
Thinking tokens
Reasoning Tiers
Newest models support deep reasoning tracks which add internal processing token costs.
Verdict
The undisputed size champion. Extremely efficient unigram tokenizer. Standard pricing doubles above 200k context.
ContextCrunch tip
Utilize Gemini for huge document analysis. Use prompt caching if doing multiple queries against the same large files to save 90% cost.
